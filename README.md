## Architecture & Engineering Stack

This portfolio is engineered as a high-performance, editorial digital publication inspired by minimalist Swiss typography and kinetic 3D stagecraft.

- **Framework:** Next.js 16 (App Router, Turbopack, Partial Prerendering)
- **UI & Runtime:** React 19, TypeScript, Tailwind CSS
- **Motion & Kinetic UI:** GSAP (GreenSock), Lenis Smooth Scroll
- **3D Interactive Stage:** Three.js, React Three Fiber (`@react-three/fiber`), Drei (`@react-three/drei`), 3D CSS Cylindrical Projection
- **Sound FX Engine:** Synthesized Web Audio API micro-interactions
- **Contact Dispatch:** Asynchronous verified inbox routing with cryptographic audit feedback

## Local Development

```bash
# Clone the repository
git clone https://github.com/Jeffrey978/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start the Turbopack development server
npm run dev

# Compile production build
npm run build
```
